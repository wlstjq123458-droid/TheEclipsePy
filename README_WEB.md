# 창공시스템 웹 버전

데스크톱 프로그램과 같은 기능을 브라우저에서 쓰는 버전입니다. 관리자가 로그인해서 쓰고,
얼굴인식 출결 기록은 서버로 모여서 [데이터 관리]에서 조회합니다.

## 내 컴퓨터에서 실행 (테스트)

```bash
python -m pip install -r requirements-web.txt
python run_web.py
```

브라우저에서 <http://127.0.0.1:8002> 을 엽니다.

- 첫 화면에서 관리자 비밀번호를 정합니다. 아이디는 `admin`입니다.
- 첫 실행 때 C# 프로그램 데이터(`%APPDATA%\SeatManagerApp`)를 복사해 옵니다. 원본은 건드리지 않습니다.
  이후로는 웹 데이터가 따로 관리되므로 C# 프로그램에서 고친 내용은 웹에 반영되지 않습니다.
- 구글 서비스 계정 키도 함께 복사되므로, 서버를 켜면 구글 시트 자동 동기화가 바로 시작됩니다.
- 웹 데이터 위치: `%APPDATA%\SeatManagerApp-Web` (Linux는 `~/.seatmanager-web`). `--data-dir`로 바꿀 수 있습니다.

## 학교 서버에 올리기

1. 서버에 Python 3.10 이상을 설치하고 이 폴더를 복사합니다. PySide6는 필요 없습니다.
2. `python -m pip install -r requirements-web.txt`
3. 지금까지 쓰던 데이터를 옮기려면 내 컴퓨터의 `%APPDATA%\SeatManagerApp-Web` 폴더를 서버의 데이터 폴더로 복사합니다.
   학생 개인정보와 구글 키가 들어 있으니 USB나 공유 폴더에 남기지 마세요.
4. 비밀번호를 정합니다: `python run_web.py --set-password`
5. 서버를 켭니다: `python run_web.py --host 0.0.0.0 --port 8000`
6. 다른 컴퓨터의 브라우저에서 `http://서버IP:8000` 으로 접속합니다. 안 되면 서버 방화벽의 해당 포트를 확인합니다.

비밀번호를 정하지 않으면 외부 공개 모드로 시작되지 않습니다. 서버가 재부팅돼도 자동으로 켜지게 하려면
Windows는 작업 스케줄러, Linux는 systemd에 5번 명령을 등록합니다.

### 꼭 확인할 것

- **HTTPS**: `http://`로 접속하면 비밀번호와 학생 정보가 암호화 없이 전송됩니다. 교내망이라도 인증서를 받아서
  `--ssl-cert 인증서.pem --ssl-key 개인키.pem`으로 켜는 것을 권합니다.
- **접속 범위**: 서버 IP가 학교 밖에서도 열리는지 확인하고, 가능하면 교내망으로 제한합니다.
- **백업**: 데이터는 데이터 폴더의 JSON 파일입니다. 이 폴더를 정기적으로 복사해 두면 됩니다.
- **서버 한 대, 프로세스 하나**: 데이터를 메모리에 두고 동작을 차례로 처리하므로 프로세스를 여러 개 띄우면 안 됩니다.

## 얼굴인식 연동

| 구성 | 방법 |
|---|---|
| 얼굴인식 프로그램이 서버와 같은 컴퓨터 | 설정 없이 동작합니다. 같은 폴더(`~/SeatManagerApp/face-integration`)의 파일을 읽고 씁니다. |
| 얼굴인식이 다른 컴퓨터·라즈베리파이 | 그 컴퓨터에서 아래 연동 프로그램을 켜 둡니다. |

```bash
python tools/face_bridge.py --server http://서버IP:8000 --key 연동키
```

- 연동 키는 웹의 [설정] → [얼굴인식 출결 연동]에 있습니다. 관리자 비밀번호와 별개입니다.
- `tools/face_bridge.py` 파일 하나만 복사하면 됩니다. 파이썬 기본 기능만 쓰므로 추가 설치가 없습니다.
- 30초마다 `attendance.json`이 바뀌었으면 서버로 올리고, 서버의 학생 명단을 `roster.json`으로 받아 옵니다.
  얼굴인식 프로그램은 고치지 않아도 됩니다.
- 얼굴인식 PC가 재부팅돼도 켜지도록 시작 프로그램에 등록해 두세요.

연동 프로그램 없이 직접 연결하려면 API를 쓰면 됩니다. 두 요청 모두 `X-API-Key` 헤더에 연동 키가 필요합니다.

| 요청 | 내용 |
|---|---|
| `POST /api/face/attendance` | `attendance.json`과 같은 형식의 출결 전체 |
| `GET /api/face/roster` | `roster.json`과 같은 형식의 학생 명단 |

## 데스크톱과 다른 점

- 관리자 로그인, 비밀번호 변경, 얼굴인식 연동 키가 추가되었습니다.
- 화면 해상도 설정은 없습니다. 브라우저 창 크기를 따릅니다.
- 좌석 고정·삭제 모드와 정보 가리기는 각 브라우저 화면에서만 적용됩니다.
- 다른 관리자가 바꾼 내용과 구글 폼 새 신청은 10초 안에 자동으로 화면에 반영됩니다.
  창을 열어 둔 동안이나 입력 중에는 끝날 때까지 기다립니다.
