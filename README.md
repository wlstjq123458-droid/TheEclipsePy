# 동서대학교 좌석 및 기자재 관리 시스템 — Python 버전

기존 C# / WPF 버전(`TheEclipse` 폴더)과 별개로 새로 만든 Python(PySide6) 버전입니다.
C# 버전은 그대로 두었고, 데이터 저장 폴더도 따로 씁니다 — 두 프로그램이 같은 컴퓨터에서
동시에 있어도 서로 데이터를 덮어쓰지 않습니다. (얼굴인식 연동 폴더만 예외로, C# 버전과
똑같은 위치를 공유합니다 — 아래 "얼굴인식 연동" 참고.)

**UI도 C# 버전과 같은 디자인을 씁니다**: 왼쪽 남색(#0A1C3E) 사이드바 + 로고 + 메뉴 버튼(선택된
메뉴는 파란색 강조), 흰색 헤더 바(현재 화면 제목 + 상상Lab/캐비닛/기자재 승인 대기 알림 카드 +
오늘 날짜), 옅은 회색 작업 영역에 흰색 카드(둥근 모서리 + 옅은 테두리)를 배치하는 구성과 색상
(파랑 #2563EB·초록 #10B981·빨강 #EF4444·주황 #F97316 등)을 그대로 옮겼습니다. `app/theme.py`에
색상 값과 전역 스타일시트가 있고, 상단 탭 방식(QTabWidget) 대신 C# 버전과 같은 좌측 사이드바 +
페이지 전환 방식(`app/main_window.py`)으로 바꿨습니다.

## 실행 방법

```bash
pip install -r requirements.txt
python run.py
```

## 설치용 실행파일(.exe) 만들기

```bash
pip install pyinstaller
python build_exe.py
```

`dist/SeatManagerApp-Python.exe` 하나로 배포할 수 있습니다(단일 파일, 콘솔창 없음). 실제로
빌드해서 실행까지 확인했습니다. Inno Setup 등으로 감싸 정식 설치파일(Setup.exe)을 만들고
싶으면 C# 버전의 `installer/SeatManagerApp.iss`를 참고해 `dist` 폴더를 Source로 지정하면 됩니다.

## 구현된 기능

- **대시보드**: 오늘 날짜로 현재 학사 시즌 자동 판별, 좌석/캐비닛/본체/노트북 대여 현황과
  승인 대기 건수 요약 카드, 메모장(추가/수정/삭제).

- **좌석 배정**: 52석 배치(기둥 포함, C# 버전과 동일한 위치), 좌석 클릭→상세보기/수정/신규배정/
  좌석비우기, 드래그로 좌석 맞바꾸기(고정 좌석 보호 팝업, 대학원생 좌석 자동 고정), 좌석 고정
  모드/삭제 모드, 랜덤 배정, 정보 가리기, 좌석데이터 불러오기(상상Labs 응답 CSV/엑셀), 연도·학기별
  독립 저장.

- **캐비닛 현황**: 48칸(1페이지 1~24번 / 2페이지 25~48번), 빈 칸 배정(마스터에서 선택 또는 직접
  입력 + 대여 기간 캘린더), 상세보기/정보수정/다른 번호로 이동/반납 처리, 드래그로 이동·맞바꾸기,
  검색 강조, 반납 임박 빨간 표시, 중복 배정 차단.

- **기자재 현황**: 본체(10대)·노트북(20대) 대여 현황을 따로 보여주고, 새 대여 등록(마스터에서
  선택 가능), 반납 처리 + 반납 취소(되돌리기), 엑셀/CSV 가져오기(양식 자동 인식, 학번/연락처
  앞자리 0 복원, 기자재 종류가 다른 줄은 건너뜀), 엑셀 추출, 대여 이력 조회, 기자재 상태 관리
  (고장/수리/기타 등록 및 처리 완료).

- **승인 대기**: 구글 시트(상상Lab·캐비닛·기자재 신청 응답)를 동기화해서 승인/반려. 승인하면
  마스터 학생에 등록/갱신되고, 캐비닛·기자재 신청은 빈 자리에 바로 배정됩니다. 상상Lab 승인은
  좌석을 자동 배정하지 않습니다(이 프로젝트에서 이전에 정한 방침과 동일) — [좌석 배정] 탭의
  [랜덤 배정]으로 배치하면 됩니다. `google-api-python-client`가 없거나 서비스 계정 키가
  없어도 앱이 죽지 않고 안내 메시지만 뜹니다(실제 구글 시트로 테스트하지는 못했습니다 — 가짜
  응답 데이터로 파싱·중복 제거·승인/반려 로직만 검증했습니다).

- **데이터 관리**: 마스터 학생 데이터베이스(학번/이름/소속/지도교수/연락처/이메일) 검색/추가/
  수정/삭제/전체 삭제, 엑셀/CSV 가져오기(헤더 자동 인식).

- **설정**: 학사 시즌 일정 관리(연도별 1학기/여름방학/2학기/겨울방학 시작·종료일, 연도 추가/삭제),
  구글 폼 연동 설정(시트 URL 3종 + 서비스 계정 키 파일 등록).

- **얼굴인식 연동**: 마스터 학생 목록을 저장할 때마다 `roster.json`을 자동으로 내보내고, 얼굴인식
  프로그램(`insightface-attendance`)이 적어 둔 `attendance.json`을 읽을 수 있는 함수를 갖췄습니다
  (`app/face_integration.py`). C# 버전(`FaceIntegration.cs`)과 정확히 같은 폴더
  (`%USERPROFILE%\SeatManagerApp\face-integration\`)·같은 JSON 스키마를 쓰므로 얼굴인식
  프로그램은 C#/Python 어느 쪽을 켜 두어도 그대로 통신합니다. (출결 목록을 보여주는 화면은
  아직 없고, 데이터를 읽어오는 함수까지만 만들었습니다.)

## 테스트 방법

실제 창을 마우스로 눌러보며 확인하지는 못했습니다 — Qt를 화면 없이 띄우는
`QT_QPA_PLATFORM=offscreen` 환경에서 각 기능의 내부 로직을 직접 호출해 검증했습니다
(가져오기 파싱, 드래그 이동/맞바꾸기, 반납/되돌리기, 구글 시트 동기화(가짜 데이터)·승인/반려,
얼굴인식 파일 내보내기/읽기, 저장 후 다시 불러오기 등). 설치용 exe는 실제로 빌드해서 잠깐
띄워 크래시 없이 뜨는 것까지 확인했습니다.

## 데이터 저장 위치

- `%APPDATA%\SeatManagerApp-Python\seats.json` — 시즌별 좌석 데이터
- `%APPDATA%\SeatManagerApp-Python\appstate.json` — 마스터 학생, 캐비닛 배정, 기자재 대여/이력,
  기자재 상태, 승인 대기/이력, 메모
- `%APPDATA%\SeatManagerApp-Python\seasons.json` — 학사 시즌 일정
- `%APPDATA%\SeatManagerApp-Python\settings.json` — 구글 폼 연동 설정
- `%APPDATA%\SeatManagerApp-Python\google-service-account.json` — 구글 서비스 계정 키
- `%USERPROFILE%\SeatManagerApp\face-integration\` — 얼굴인식 프로그램과 주고받는 roster.json/attendance.json (C# 버전과 공유)

## 남은 것 / 알려진 제약

- 구글 시트 연동은 실제 시트로 테스트하지 못했습니다. 응답 열 이름이 예상과 많이 다르면
  (예: "학번"·"이름" 문구가 아예 없는 시트) 자동 인식에 실패할 수 있습니다.
- 캐비닛 기본 대여 기간은 학사 시즌 종료일을 우선 쓰고, 없으면 "오늘부터 한 달"입니다
  (C# 버전과 같은 우선순위).
- 대시보드의 승인 대기 건수는 [승인 대기] 탭과 같은 데이터를 보여줍니다. 상상Lab/캐비닛/기자재
  건수를 따로 나눠 보여주지는 않습니다.
- 얼굴인식 출결 데이터를 보여주는 화면(테이블)은 아직 없습니다 — 읽어오는 함수(`load_attendance`)만
  있습니다.
